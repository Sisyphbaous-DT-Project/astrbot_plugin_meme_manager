## 代码对照确认（未单独跑浏览器断言）

- [x] paste 只从 `clipboardData.items` 收集文件，不碰 `files`，不重复入队
- [x] input/textarea/contenteditable 中的文字粘贴直接放行
- [x] 只有收到图片文件时才 `preventDefault()`；纯文本/HTML/图片链接不拦截、不下载远程图
- [x] 三个入口（选择/拖拽/粘贴）统一进 `enqueueFiles` → 待添加预览弹窗
- [x] 批次目标分类在确认时快照（`batchCategory`），处理中禁止切换
- [x] "取消剩余"只把未发出的 pending 项标 cancelled，已发出项如实保留
- [x] Blob URL：入队创建；移除项/清空整批/弹窗最终关闭/`beforeunload` 时 revoke；上传完成但弹窗未关时不释放
- [x] 主预览只解码当前选中项；侧栏缩略图用 `createImageBitmap` 静态首帧（失败回退原图 URL）
- [x] R10 添加前预览支持 适应窗口/原始尺寸 切换（`upload-zoom` 按钮，原始尺寸时容器滚动）
- [x] 上传/预览 API 响应顶层无 `data` 键，图片内容字段为 `content`
- [x] 上传传原始分类名，不手动 encodeURIComponent
- [x] 不使用原生 alert/confirm/prompt，全部页面内弹窗/toast
- [x] 登录失效识别为 authExpired，明确提示，不循环重试
- [x] 列表/大图请求带序号，过时响应丢弃（切分类/翻页不串图）
- [x] 缩略图按 category/name/mtime 缓存，勾选不重发 thumb 请求
